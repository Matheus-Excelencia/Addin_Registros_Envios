# Testes da Alpha 2.0

Registre aqui roteiros e resultados de testes realizados exclusivamente com dados fictícios.

## Verificações iniciais
- [ ] Campos obrigatórios impedem envio incompleto.
- [ ] E-mail inválido é rejeitado.
- [ ] CPF inválido é rejeitado pelos dígitos verificadores.
- [ ] A opção “Testemunha do credor? = Sim” exibe os campos condicionais.
- [ ] A opção “Não” oculta os campos da testemunha.
- [ ] Limpar formulário remove os valores de teste.
- [ ] CPF aparece parcialmente mascarado na prévia.
- [ ] Nenhum dado é enviado a Excel, SharePoint ou backend no protótipo atual.

Não usar CPF ou dados pessoais reais.
