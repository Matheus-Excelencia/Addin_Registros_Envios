# Manifestos de teste

O manifesto específico da Alpha 2.0 será colocado nesta pasta, separado do manifesto estável.

Antes de criá-lo, é obrigatório:
1. Publicar a Alpha 2.0 em uma URL de Preview exclusiva e verificável.
2. Confirmar que a URL abre no contexto de teste do Excel Web.
3. Usar um GUID de suplemento diferente do manifesto estável.
4. Apontar taskpane, comandos, ícones e domínios somente para a implantação da Alpha 2.0.
5. Verificar que o manifesto não referencia a URL de produção da Alpha 1.05.

Não instalar enquanto a URL de Preview e os endereços de recursos não forem confirmados.
